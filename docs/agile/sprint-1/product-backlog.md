## Definition of Done

Sebuah item dianggap selesai jika:

- Fitur berjalan sesuai acceptance criteria di `user-stories.md`
- Tampilan responsif di mobile dan desktop
- Kode sudah di-merge ke `main` lewat Pull Request
- Commit dan branch mengikuti aturan penamaan
- Kartu di board dipindahkan ke kolom Done

## Aturan Pengelolaan Backlog

- Item baru dimasukkan sebagai issue GitHub, lalu masuk kolom Backlog.
- Prioritas ditinjau ulang pada setiap Sprint Planning.
- Item yang dipilih untuk sprint dipindahkan ke kolom Sprint.
