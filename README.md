- Next.js, TypeScript

## Cara Menjalankan

### Lokal

```bash
npm install
npm run dev
```

Buka http://localhost:3000.

### Dengan Docker

```bash
docker run --rm -p 3000:3000 hafidzzuliesky/hello-deutsch:v1-UTS
```
